La función print()

Muestra información en pantalla:

nombre = "Maíz"
etc_mm = 5.2

print("El cultivo es:", nombre)
print(f"La ETc del {nombre} es {etc_mm} mm/día")

# f-strings: permiten insertar variables con {}
print(f"{etc_mm:.2f} mm/día")    # formatea a 2 decimales
El cultivo es: Maíz
La ETc del Maíz es 5.2 mm/día
5.20 mm/día

Tip

Usa f-strings (f"texto {variable}") para mensajes claros con unidades.

Listas — colecciones ordenadas

# Crear listas
cultivos = ["Maíz", "Trigo", "Palta", "Vid"]
temperaturas = [22.5, 18.3, 25.1, 20.0]

# Acceder por índice (empieza en 0)
cultivos[0]       # "Maíz"
cultivos[-1]      # "Vid" (último)

# Operaciones con listas
len(cultivos)     # 4 (cantidad de elementos)
cultivos.append("Manzana")   # agregar al final
# Recorrer una lista
for cultivo in cultivos:
    print(f"Cultivo: {cultivo}")

Introducción a numpy

numpy es la librería fundamental para cálculos numéricos en Python:

import numpy as np          # así se importa

# Arrays: como listas pero optimizadas para matemáticas
valores = np.array([1, 2, 3, 4, 5])

# Operaciones sobre todo el array
valores * 2                 # [2, 4, 6, 8, 10]
valores + 10                # [11, 12, 13, 14, 15]
valores.mean()              # 3.0 (media)
valores.std()               # desviación estándar

# Verificar resultados
np.allclose([1.0, 2.0], [1.001, 1.999], atol=0.01)  # True

np.allclose es clave: aparece en las celdas de validación de los talleres.

Introducción a pandas — DataFrames

pandas es la librería para trabajar con datos tabulares (filas y columnas):

import pandas as pd

# Crear un DataFrame — como una planilla Excel en Python
datos = pd.DataFrame({
    'Producto': ['Palta', 'Maíz', 'Trigo'],
    'Rendimiento_ton_ha': [12, 14, 7],
    'Precio_USD_ton': [2500, 220, 300]

Operaciones básicas con pandas

# Acceder a una columna
datos['Producto']              # Serie (columna)
datos['Precio_USD_ton']        # valores de precio

# Crear nueva columna
datos['Ingreso_USD_ha'] = (
    datos['Rendimiento_ton_ha'] * datos['Precio_USD_ton']
)

# Filtrar filas por condición
caros = datos[datos['Precio_USD_ton'] > 1000]

# Estadísticas rápidas
datos['Rendimiento_ton_ha'].mean()    # media
datos['Rendimiento_ton_ha'].max()     # máximo

Introducción a matplotlib

import matplotlib.pyplot as plt

# Datos
cultivos = ['Palta', 'Maíz', 'Trigo']
huella = [2080, 950, 1370]

# Crear gráfico de barras
fig, ax = plt.subplots()
ax.bar(cultivos, huella)
ax.set_xlabel('Cultivo')
ax.set_ylabel('Huella hídrica (L/kg)')
ax.set_title('Huella hídrica por cultivo')
plt.show()

Gráfico de barras horizontales

# Ordenar datos para mejor visualización
datos_ordenados = sorted(zip(huella, cultivos))
huella_ord = [h for h, c in datos_ordenados]
cultivos_ord = [c for h, c in datos_ordenados]

# Barras horizontales
fig, ax = plt.subplots()
ax.barh(cultivos_ord, huella_ord)
ax.set_xlabel('Huella hídrica (L/kg)')
ax.set_title('Huella hídrica por producto')
plt.tight_layout()
plt.show()

Tip

barh() crea barras horizontales. Usa tight_layout() para evitar que se corten las etiquetas.
