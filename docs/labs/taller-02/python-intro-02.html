suelos = pd.DataFrame({

Escalas logarítmicas — semilogx()

Las curvas de retención usan escala logarítmica en el eje X porque cubren varios órdenes de magnitud (0 → 1500 kPa):

fig, ax = plt.subplots(figsize=(12, 6))

# semilogx: eje X logarítmico, eje Y lineal
ax.semilogx(curvas['Psi_kPa'], curvas['Arenoso'],
            'o-', linewidth=2, label='Arenoso')
ax.semilogx(curvas['Psi_kPa'], curvas['Franco'],
            's-', linewidth=2, label='Franco')

ax.set_xlabel('Potencial mátrico |Ψm| (kPa) — escala log')
ax.set_ylabel('θv (cm³/cm³)')
ax.legend()
ax.grid(True, alpha=0.3)
plt.show()

Líneas de referencia verticales

# Líneas verticales para CC y PMP
ax.axvline(x=33, color='blue', linestyle='--',
           alpha=0.5, label='CC (-33 kPa)')
ax.axvline(x=1500, color='red', linestyle='--',
           alpha=0.5, label='PMP (-1500 kPa)')
Función Uso
axvline(x) Línea vertical en x
axhline(y) Línea horizontal en y
color= Color de la línea
linestyle='--' Línea punteada
alpha=0.5 Transparencia (0 = invisible, 1 = opaco)

scipy.interpolate — interpolar curvas

Cuando tienes puntos discretos y necesitas valores intermedios:

from scipy.interpolate import interp1d

# Crear función de interpolación
f_interp = interp1d(curvas['Psi_kPa'], curvas['Arenoso'],
                     kind='linear')

# Estimar θv a un Ψm que no está en la tabla
theta_100 = f_interp(100)   # ≈ 0.07
theta_200 = f_interp(200)   # valor estimado entre 100 y 500

Tip

kind='linear' interpola linealmente. También existe kind='cubic' para curvas más suaves.

Gráfico de dispersión (scatter plot)

Para visualizar datos espaciales:

fig, ax = plt.subplots(figsize=(12, 5))

# scatter: puntos coloreados por una tercera variable
scatter = ax.scatter(
    datos['X_m'], datos['Y_m'],
    c=datos['Theta_v'],        # color según θv
    cmap='Blues',              # paleta de colores
    s=100,                     # tamaño de punto
    edgecolors='black'         # borde
)

# Barra de color
plt.colorbar(scatter, label='θv (cm³/cm³)')

ax.set_xlabel('Coordenada X (m)')
ax.set_ylabel('Coordenada Y (m)')
ax.set_title('Variabilidad espacial de humedad')
plt.show()

Coeficiente de variación (CV)

Evalúa la variabilidad relativa de los datos:

\[CV = \frac{\sigma}{\bar{x}} \times 100\]

media = datos['Theta_v'].mean()
desviacion = datos['Theta_v'].std()
cv = (desviacion / media) * 100

print(f"CV: {cv:.1f}%")

# Interpretación agronómica
if cv < 15:
    print("Baja variabilidad → manejo uniforme posible")
elif cv < 35:
    print("Variabilidad moderada → considerar manejo diferenciado")
else:
    print("Alta variabilidad → riego de precisión recomendado")
